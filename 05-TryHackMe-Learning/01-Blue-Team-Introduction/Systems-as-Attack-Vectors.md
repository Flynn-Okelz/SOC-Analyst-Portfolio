## Overview
Completed a practical Blue Team lab examining system vulnerabilities, misconfigurations and supply chain attacks, with a focus on identifying risks and applying appropriate security controls.

## Key Concepts
- **System Criticality:** Understanding how compromised endpoints, servers and cloud platforms can impact organisations.
- **Vulnerability Management:** Identifying security weaknesses and applying patches to reduce exposure.
- **Zero-Day Vulnerabilities:** Flaws exploited before vendors have released an effective patch.
- **CVE:** Common Vulnerabilities and Exposures identifiers used to track publicly disclosed vulnerabilities.
- **Misconfiguration:** Security weaknesses caused by improper system or application settings.
- **Supply Chain Attacks:** Compromising trusted software, applications or dependencies to affect downstream users.

## Remediation & Security Controls
- **Patch Management:** Regularly identify, prioritise and remediate vulnerabilities.
- **Security Training:** Educate IT personnel on system hardening and misconfiguration risks.
- **Secure Password Policy:** Enforce strong authentication practices to reduce brute-force risks.
- **Antivirus Protection:** Detect and prevent malware, including data stealers and malicious USB threats.
- **Network Protection:** Restrict access to trusted users and authorised IP addresses.
