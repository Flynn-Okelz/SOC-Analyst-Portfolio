## Practical Investigation

| Scenario | Investigation / Response |
|---|---|
| Malicious Download | Investigated a quarantined `Setup.exe` from an untrusted website and identified it as a data stealer. |

| Deepfake Impersonation | Recognised a suspicious CEO password-reset request and verified the request before acting. |
| Security Policy | Reviewed defensive policies covering antivirus, awareness training, anti-phishing and access management. |

## Defensive Measures
- Deploy antivirus and Endpoint Detection and Response (EDR).
- Implement anti-phishing solutions.
- Conduct regular security awareness training.
- Enforce identity and access management controls.
- Apply the Trust but Verify principle.
