# Lesson 1: Introduction to Security Operations Centres (SOC)

## 1. Learning Objectives

This lesson will introduce the fundamentals of Security Operations Centres (SOC).

By the end of this lesson, I aim to understand:

- What a Security Operations Centre is.
- Why organisations need SOC teams.
- The responsibilities of SOC analysts.
- The differences between Tier 1, Tier 2 and Tier 3 analysts.
- Basic security terminology.
- How a SOC monitors, investigates and responds to security alerts.
- The purpose of Security Information and Event Management (SIEM) solutions.

## 2. Topics to Study

### 2.1 Introduction to SOC
- Definition and purpose of a SOC.
- Why organisations establish SOC teams.
- Core SOC responsibilities.

### 2.2 SOC Analyst Roles
- Tier 1 – Alert Analyst.
- Tier 2 – Incident Responder.
- Tier 3 – Threat Hunter / Senior Analyst.
- Responsibilities and escalation procedures.

### 2.3 Basic Security Terminology
- Security events.
- Security alerts.
- Security incidents.
- Threats.
- Vulnerabilities.

### 2.4 SOC Monitoring and Investigation
- Security monitoring.
- Alert detection and triage.
- Evidence collection.
- Incident classification and escalation.

### 2.5 SIEM Fundamentals
- What SIEM means.
- How SIEM solutions collect and analyse logs.
- Examples of SIEM platforms.
- The role of SIEM in security operations.

### 2.6 Basic SOC Workflow
- Monitor.
- Detect.
- Investigate.
- Classify.
- Document.
- Escalate or respond.
